# FitBuddy – המאמן האישי שלך 💪

אפליקציית כושר ותזונה בעברית (RTL) לאייפון ולאנדרואיד, בנויה ב־**React Native + Expo + TypeScript**.
האפליקציה בנויה בהשראת המסכים שבתמונה שצורפה: ממשק כהה עם הדגשות ליים, יומן אימונים עם
תיעוד סטים ומשקלים, הדגמות והסברים לכל תרגיל, ומעקב תזונה יומי.

## מה יש באפליקציה

### 🏋️ אימונים
- **5 תוכניות אימון מובנות**: גוף מלא למתחילים, דחיפה/משיכה/רגליים, עליון־תחתון, אימון בית ללא ציוד, ותוכנית חיטוב.
- **מסך אימון פעיל** – בדיוק כמו בתמונה: לכל תרגיל הדגמה ויזואלית, כפתורי **החלפה / היסטוריה / הסבר / הסרה**,
  וטבלת סטים עם שדות **משקל בק"ג** ו**חזרות** וסימון וי לכל סט שהושלם.
- **טיימר מנוחה** אוטומטי שנפתח בסיום כל סט, עם רטט בסיום, השהיה ותוספת 15 שניות.
- **אימון חופשי** – בניית אימון מאפס מתוך ספריית התרגילים.
- **מסך סיכום** בסוף האימון: משך, סטים, חזרות, נפח כולל ופירוט לכל תרגיל.

### 📹 ספריית תרגילים
- **61 תרגילים** מחולקים ל־8 קבוצות שרירים, עם חיפוש וסינון.
- לכל תרגיל: **הדגמה מונפשת** של התנועה, הסבר טכניקה שלב אחר שלב בעברית,
  טיפים, טעויות נפוצות, המלצת סטים/חזרות/מנוחה, וקישור לסרטוני הדגמה ביוטיוב.
- **היסטוריה אישית** לכל תרגיל: גרף התקדמות במשקלים ושיא אישי.

### 🥗 תזונה
- **מאגר של 79 מוצרי מזון** בעברית, כולל מטבח ישראלי (חומוס, פלאפל, שקשוקה, בורקס, סביח, במבה ועוד).
- חלוקה ל־4 ארוחות ביום, מנות מוכנות מראש ("פיתה", "גביע", "חופן") או הזנה לפי גרמים.
- הזנה ידנית של פריט עם ערכים משלכם, מועדפים, ומחיקה בלחיצה.
- **חישוב יעדים אוטומטי** לפי נוסחת Mifflin-St Jeor: קלוריות, חלבון, פחמימות ושומן לפי גיל, משקל, גובה, מין, רמת פעילות ומטרה.
- מעקב שתיית מים יומי.

### 📈 התקדמות
- נפח אימון שבועי, רצף ימי אימון, סה"כ דקות ואימונים.
- מעקב משקל גוף עם גרף מגמה.
- היסטוריית אימונים מלאה עם כניסה לסיכום של כל אימון.

## הרצה

```bash
npm install
npx expo start
```

סרקו את קוד ה־QR עם אפליקציית **Expo Go** בטלפון, או הריצו על סימולטור:

```bash
npx expo start --ios      # אייפון (macOS)
npx expo start --android  # אנדרואיד
npx expo start --web      # דפדפן
```

לבנייה של קובץ התקנה אמיתי (IPA / APK) עם EAS:

```bash
npm install -g eas-cli
eas build --platform android --profile preview
eas build --platform ios
```

## מבנה הפרויקט

```
app/                      ניתוב מבוסס קבצים (expo-router)
  (tabs)/                 חמשת הטאבים: בית, אימונים, תזונה, התקדמות, פרופיל
  workout/[sessionId]     מסך האימון הפעיל
  workout/summary         סיכום אימון
  exercise/[id]           הסבר, הדגמה והיסטוריה לתרגיל
  exercise/picker         ספריית תרגילים / הוספה / החלפה
  program/[id]            פירוט תוכנית אימון
  food/search             חיפוש והוספת מזון
  onboarding.tsx          תהליך הקמת פרופיל
src/
  data/                   תרגילים, מזון, תוכניות אימון
  store/                  ניהול מצב + שמירה ב-AsyncStorage
  components/             רכיבי UI, טבעות מאקרו, גרפים, טיימר, הדגמה
  theme/                  צבעים, מרווחים ותמיכת RTL
  utils/                  תאריכים, חישובי תזונה, מדיה
```

## הערות על המדיה

- **הדגמות התרגילים** מגיעות ממאגר [free-exercise-db](https://github.com/yuhonas/free-exercise-db)
  (רישיון Public Domain). לכל תרגיל שני פריימים – התחלה וסיום – שהאפליקציה מנפישה בלולאה
  כדי להראות את התנועה. התמונות נטענות מהרשת ונשמרות במטמון על ידי `expo-image`.
- **סרטוני וידאו**: הקוד תומך בהטמעת סרטון לכל תרגיל דרך השדות `videoUrl` (קובץ mp4/hls)
  או `youtubeId` ב־`src/data/exercises.ts`. כרגע השדות ריקים כי לא נכללים כאן סרטונים
  שאין לנו רישיון להפיץ – בכל מסך תרגיל יש כפתור שפותח סרטוני הדגמה ביוטיוב.
  אם יש לכם סרטונים משלכם, מלאו את `youtubeId` או `videoUrl` והם ייטענו בתוך האפליקציה.

## פרטיות

כל הנתונים – אימונים, תזונה, שקילות והפרופיל – נשמרים **מקומית במכשיר** ב־AsyncStorage.
אין שרת, אין חשבון ואין שליחת מידע החוצה.

## אזהרה

האפליקציה מספקת מידע כללי בלבד ואינה תחליף לייעוץ רפואי או לליווי של מאמן מוסמך.
התייעצו עם רופא לפני תחילת תוכנית אימונים או תזונה.
